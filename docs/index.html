Your AI penetration testing assistant, running entirely on your machine.

HackerBrain OS is a local AI-powered assistant for Kali / Parrot Linux. It connects to your own local models, detects your installed security tools, and automates reconnaissance, vulnerability scanning, and bug bounty workflows — no cloud, no data leaves your computer.

Everything a pentest needs, local-first

HackerBrain OS orchestrates the tools already on your system and lets a local AI engine plan, execute and analyze engagements.

Autonomous agent

Ask in plain language (EN/ES): the agent plans steps with your local model, executes real commands, and iterates until the goal is reached.

Vulnerability scanning

Port, service, IoT and template-based vulnerability scans (Nmap, Nuclei, masscan) with severity classification and CVE correlation.

Tech fingerprinting

Identifies the web stack (frameworks, servers, WAFs) and summarizes the likely attack surface before you start.

Encrypted vault

Credentials and findings stored with PBKDF2 + AES encryption. Nothing leaves your machine.

EN / ES interface

Full bilingual interface and tutorials. The assistant answers in the language you write in.

Bug bounty workflows

Subdomain enumeration, directory fuzzing, header analysis, brute-force gates with explicit confirmation, and DNS recon/spoofing tests.

OSINT module

Domain, email, username, phone, IP and metadata intelligence over public sources — WHOIS, DNS, certificate transparency, breach checks and social profile probing.

Desktop app

Native windowed version (pywebview) with one-command automatic installation. No browser needed.

Rate-limit aware

Scans report estimated durations up front and throttle automatically (nuclei -rl, nmap --max-rate) when a target enforces limits.

Install in one command

git clone https://github.com/Cyt3rTo0ls/hackerbrain-os.git
cd hackerbrain-os
./install.sh          # creates venv, installs deps, initializes the DB
./install.sh run      # start on http://127.0.0.1:8080

Desktop version (native window, automatic setup):

./desktop/run.sh      # installs everything and opens the desktop app
Requirements: Python 3.10+, Kali / Parrot / Debian-based Linux, and a local chat-completions engine (any local LLM server — the engine URL is configured in data/config.yaml). The rest of the platform works without an engine, but conversational analysis needs one.
